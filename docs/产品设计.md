# 产品设计：输入栏常驻模型切换器（v1.22）

## 背景

用户在手机端找不到模型切换入口。实际原因：v1.21 源码里模型拨盘（`composer.reasoning`）**只在输入框展开态显示**，而查看会话时输入栏处于收起态（[+] [输入框] [麦克风] [发送/停止]），拨盘完全不可见；设置页里也没有直达「模型」的入口（藏在拨盘 → 进阶设置两层之下）。电脑端 ZCode 的「选择模型」则是常驻可见的。

## 本版做什么（MVP）

1. **输入栏常驻模型胶囊 chip**：在输入栏上方（输入玻璃面板内部第一行）加一个紧凑胶囊，显示「当前模型名 + 思考强度标签」，收起态和展开态都可见（语音输入态除外）。
   - 点击 chip = 打开现有推理面板（模型名行 + 思考强度滑条），行为与现有拨盘完全一致。
   - 点击面板里的模型名行 = 进入现有「进阶」模型选择表（按电脑端配置列出全部可用/不可用模型）。
   - 无连接/未配置时显示「沿用电脑配置」，与现有文案一致。
2. **版本号 1.21 → 1.22**（MARKETING_VERSION + CURRENT_PROJECT_VERSION 22），同步更新 UI 测试里的版本号断言。
3. **UI 测试补断言**：收起态断言 `composer.modelChip` 存在；点击后断言 `reasoning.advanced` 面板出现。用 CI 的模拟器验证兜底。

## 本版不做什么（边界外）

- ❌ 设置页新增独立「模型」入口（涉及 sheet 叠层风险，下版再做）
- ❌ 改动桥接协议 / 电脑端任何代码（现有 `switchModelConfig` 链路已够用）
- ❌ 模型列表缓存、自定义模型管理、按会话记忆等增强
- ❌ 电脑端 ZCode 桌面 App 的任何改动

## 交互细节约定

- chip 与语音输入互斥：`voiceActive` 时隐藏（与输入栏其它控件一致）。
- chip 样式走现有 `ZTheme` + `compatGlassEffect` 兼容层，不引入 iOS 17+ 专属 API。
- 权限不足（`canEditSettings` 为 false）时 chip 仍可点开面板，由面板内部按现有逻辑禁用滑条——与拨盘行为保持一致。
